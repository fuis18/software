Catálogos de iconos, SVGs y avatares para no reinventar los assets visuales en cada proyecto.

## Iconos

| Recurso                | Enlace                                                                 | Qué ofrece                                               |
| ---------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------- |
| **Icônes**             | [https://icones.js.org](https://icones.js.org)                         | Buscador de packs de iconos, copia/paste listo para usar |
| **Iconify**            | [https://icon-sets.iconify.design/](https://icon-sets.iconify.design/) | Sets de iconos unificados, un solo componente para todos |
| **Feather Icons**      | [https://feathericons.com/](https://feathericons.com/)                 | Iconos simples y minimalistas                            |
| **SVGRepo**            | [https://www.svgrepo.com/](https://www.svgrepo.com/)                   | Repositorio de iconos en SVG                             |
| **HolaSVG**            | [https://icons.holasvg.com/](https://icons.holasvg.com/)               | Iconos minimalistas                                      |
| **Flaticon**           | [https://www.flaticon.es/](https://www.flaticon.es/)                   | Iconos estilo sticker                                    |
| **Tabler Icons**       | [https://tabler-icons.io](https://tabler-icons.io)                     | Iconos SVG, set grande y consistente                     |
| **Skill Icons**        | [https://skillicons.dev/](https://skillicons.dev/)                     | Iconos de tecnologías/stacks para READMEs                |
| **SVGL**               | [https://svgl.app/](https://svgl.app/)                                 | Logos en SVG                                             |
| **Dashboard Icons**    | [https://dashboardicons.com/icons/](https://dashboardicons.com/icons/) | Iconos para dashboards y self-hosted apps                |
| **Pixel Icon Library** | [https://pixeliconlibrary.com/](https://pixeliconlibrary.com/)         | Iconos estilo pixel art                                  |
