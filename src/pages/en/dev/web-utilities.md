## JavaScript Tools

| Tool            | Use                                                     |
| --------------- | ------------------------------------------------------- |

| **Reveal.js**   | Create presentations/slides in HTML                     |
| **Eleventy**    | Transforms markdown into HTML while preserving styling  |
| **date-fns**    | Immutable, modular date utilities (parse, format, diff) |
