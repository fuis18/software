## Animations and Graphics

| Category   | Library           | Use                                                       |
| ---------- | ----------------- | --------------------------------------------------------- |
| Animations | **Framer Motion** | Declarative animations for React, transitions and gestures |
| Graphics   | **Recharts**      | Data visualization and charts                              |
| Functions  | **function-plot** | Plot mathematical functions                                |

### Animation, piece by piece

| Technology          | What it is                                  | What it's for                                      |
| ------------------- | ------------------------------------------- | -------------------------------------------------- |
| **SVG**             | XML-based vector image format               | Create scalable and interactive vector graphics     |
| **Canvas**          | HTML element                                | Drawing surface for graphics                        |
| **WebGL**           | Browser API                                 | High-performance 2D/3D graphics rendering           |
| **three.js**        | JS library                                  | Makes working with WebGL and 3D easier              |
| **React Three Fiber** | Framework built on three.js              | Use three.js declaratively within React             |
