## Learning Path

The recommended order for frontend web development:

### 1. Fundamentals

- **HTML/CSS**: semantic markup, flexbox, grid, responsive design
- **JavaScript**: ES6+, DOM manipulation, async/await, modules
- **TypeScript**: static typing, interfaces, generics

### 2. Core Framework

Choose one based on project needs:

- **React**: largest ecosystem, most job opportunities
- **Svelte**: best performance, simplest syntax
- **Vue**: gentle learning curve, good documentation

### 3. Meta-framework

Once comfortable with a framework, add a meta-framework:

- **Astro**: for static/content sites
- **Next.js**: for public/SEO sites
- **TanStack Start**: for data-heavy apps

### 4. Styling

- **Tailwind CSS**: utility-first, fast development
- **CSS Modules**: scoped styles, no runtime
- **Styled Components**: CSS-in-JS, dynamic styles

### 5. State Management

- **React Query / TanStack Query**: server state
- **Zustand**: client state, minimal API
- **Jotai**: atomic state, fine-grained updates

### 6. Testing

- **Vitest**: unit and integration tests
- **Playwright**: end-to-end testing
- **Testing Library**: component testing
