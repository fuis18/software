Catalogs of icons, SVGs, and avatars to avoid reinventing visual assets for every project.

## Icons

| Resource               | Link                                                                   | What it offers                                             |
| ---------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------- |
| **Icônes**             | [https://icones.js.org](https://icones.js.org)                         | Icon pack search engine, copy/paste ready to use           |
| **Iconify**            | [https://icon-sets.iconify.design/](https://icon-sets.iconify.design/) | Unified icon sets, a single component for all              |
| **Feather Icons**      | [https://feathericons.com/](https://feathericons.com/)                 | Simple and minimalist icons                                |
| **SVGRepo**            | [https://www.svgrepo.com/](https://www.svgrepo.com/)                   | SVG icon repository                                        |
| **HolaSVG**            | [https://icons.holasvg.com/](https://icons.holasvg.com/)               | Minimalist icons                                           |
| **Flaticon**           | [https://www.flaticon.es/](https://www.flaticon.es/)                   | Sticker-style icons                                        |
| **Tabler Icons**       | [https://tabler-icons.io](https://tabler-icons.io)                     | SVG icons, large and consistent set                        |
| **Skill Icons**        | [https://skillicons.dev/](https://skillicons.dev/)                     | Technology/stack icons for READMEs                         |
| **SVGL**               | [https://svgl.app/](https://svgl.app/)                                 | SVG logos                                                   |
| **Dashboard Icons**    | [https://dashboardicons.com/icons/](https://dashboardicons.com/icons/) | Icons for dashboards and self-hosted apps                  |
| **Pixel Icon Library** | [https://pixeliconlibrary.com/](https://pixeliconlibrary.com/)         | Pixel art style icons                                      |
| **react-icons**        | React library                                                          | Aggregates multiple packs (Feather, Material, FontAwesome, etc.) in a single component |
