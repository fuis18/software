Por lenguaje y tema — casi todos son juegos o retos interactivos: se aprende haciendo, no leyendo. Complementa los caminos de [web-roadmap](../web-roadmap/) y [back-roadmap](../back-roadmap/).

## Aprender programación

- **Git** — [learngitbranching.js.org](https://learngitbranching.js.org/?locale=es_ES) (en español, ramas y merges paso a paso) y [ohmygit.org](https://ohmygit.org) (juego para dominar los comandos): para dejar de temerle a `git rebase`.
- **Python** — [aprendepython.es](https://aprendepython.es) es el curso en español que lo cubre todo con ejercicios; [codedex.io](https://codedex.io) es un RPG de código con misiones y niveles para quien se motiva jugando.
- **CSS** — [flukeout.github.io](https://flukeout.github.io) — CSS Diner: sirves comida eligiendo el selector correcto hasta que selectores y especificidad se te queden de memoria.
- **JavaScript** — [warriorjs.com](https://warriorjs.com) — RPG por niveles donde tu héroe aprende JavaScript resolviendo salas.
- **TypeScript** — [typehero.dev](https://typehero.dev) con retos del lenguaje, y [codingame.com](https://www.codingame.com) — plataforma multi-lenguaje con retos visuales y competencias.
- **SQL** — [mystery.knightlab.com](https://mystery.knightlab.com) — *SQL Murder Mystery*: resuelves un crimen con queries; la mejor forma de practicar joins.
- **Solidity** — [cryptozombies.io](https://cryptozombies.io) — construyes un juego blockchain mientras aprendes Solidity.
- **Algoritmos** — [alg0.dev](https://alg0.dev) — visualizador con 51 algoritmos paso a paso (estructuras de datos, sorting, grafos, DP), en EN/ES, por midudev.

### Rust

- **[El Libro de Rust — módulos](https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html)** — control de alcance y privacidad con módulos: el capítulo que ordena tu código.
- **[Rust by Example — lista enlazada](https://doc.rust-lang.org/rust-by-example/custom_types/enum/testcase_linked_list.html)** — el test case clásico: una lista enlazada construida con enums.
- **[Comprehensive Rust (Google) — smart pointers](https://google.github.io/comprehensive-rust/smart-pointers/box.html)** — el curso de Google en Rust; `Box` y punteros inteligentes.
- **[Rustlings — módulos](https://github.com/rust-lang/rustlings/tree/main/exercises/10_modules)** — ejercicios corregidos para practicar módulos hasta que salgan solos.
- **[Curso completo de Rust](https://www.youtube.com/watch?v=7eyndKGmjtI&list=PL1GmZplwRjmNIdo_G2-Jl9mGEsDNHcOPe)** — playlist en español, de cero a avanzado.

## Concursos y práctica

- **[Codewars](https://www.codewars.com)** — kata graduadas por dificultad con ranking: practicar y competir de forma divertida.
- **[AdventJS](https://adventjs.dev/es)** — reto diario de JavaScript (también TypeScript y Python) cada diciembre, con ranking; comunidad hispana.
- **[LeetCode](https://leetcode.com)** — el banco de problemas por excelencia: practicar programación y preparar entrevistas técnicas.
- **[ICPC](https://icpc.global/)** — el mundial universitario por equipos (fase regional y final): algoritmos bajo presión y límite de tiempo, la competición clásica de las universidades.
- **[Codeforces](https://codeforces.com/)** — contests regulares con rating tipo Elo y divisiones: la arena diaria de la programación competitiva.

## Certificados

- **PCI Professional (PCIP)** — certificación profesional emitida por el _PCI Security Standards Council (PCI SSC)_: acredita que un profesional domina los estándares de seguridad de datos en la industria de tarjetas de pago (PCI-DSS), ideal para roles de ciberseguridad, auditoría e infraestructura en pasarelas de pago o bancos.
- **EMVCo Training** — capacitaciones oficiales sobre **EMV**, el estándar mundial para pagos con chip, _contactless_ y pagos móviles (Europay, Mastercard y Visa): los protocolos de comunicación segura entre tarjeta/dispositivo y terminales de punto de venta (POS), para desarrolladores e ingenieros.
- **Visa Developer / Visa University** — [developer.visa.com](https://developer.visa.com) para integrar los APIs de Visa, y Visa University como formación oficial de la red.
- **Mastercard Developers / M-TIP Training** — [developer.mastercard.com](https://developer.mastercard.com) para integrar pagos, y el M-TIP (_Terminal Integration Program_) para certificar la integración de terminales.
